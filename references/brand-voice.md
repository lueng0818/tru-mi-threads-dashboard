## 2. 語域分層（本檔最重要的一節）

品牌手冊第 15 頁自己就分好了：

```
IG        = 作品畫面櫥窗
Threads   = 設計師真實聲音
```

兩個平台的語域**本來就不同**，所以語氣規則要分層：

| 層 | 場域 | 語域 | 規則 owner |
|---|---|---|---|
| **品牌層** | 官網／IG 主視覺／品牌文案／slogan／簡報 | 可以凝練、有記憶點、可用對仗與金句 | 品牌手冊（Slides） |
| **Threads 互動層** | 留言、回覆、設計師日記、延伸貼文 | 以 Jessica 真實說話方式為準，大白話動作句 | `jessica-voice.md` |

### 2.1 ⚠️ 兩層不得互相否定

品牌手冊的 ✓ 範例：

```
「把你說不出口的，戴在身上。」
「告訴我你們的故事，剩下的交給我。」
```

這兩句在 `jessica-voice.md` §4 的清單裡屬於「對仗／金句」，該檔標為 0/5 避免。

**這不是矛盾，是語域不同。**

```
✅ jessica-voice.md 的「避免對仗／金句」只約束 Threads 互動層
⛔ 不得反向判定品牌手冊的範例是錯的
⛔ 也不得把品牌層的金句直接搬進 Threads 留言
```

具體風險：讀完品牌手冊之後，在留言區寫
「把你說不出口的，戴在身上」——**語域錯置**，在 Threads 會顯得像廣告。

判斷方法：**這段字會出現在哪裡？** 官網／主視覺 → 品牌層；有人在跟你講話 → 互動層。

## 3. 品牌手冊裡直接約束 Threads 的條文

以下四項**跨語域適用**，兩層都要遵守：

### 3.1 語氣三原則（品牌手冊 p.8）

```
溫度先於華麗   用有溫度的話說話，不是堆砌珠寶術語
故事先於規格   先講情感與故事，再講材質與工藝。規格是支撐，故事才是主角
陪伴先於銷售   以「我懂你、我陪你」的口吻，讓人感到被理解，成交自然發生
```

### 3.2 品牌個性四個光譜（p.8）

```
◀ 溫暖 ──────────── 冷冽 ▶
◀ 真摯 ──────────── 炫技 ▶
◀ 親近 ──────── 高高在上 ▶
◀ 雋永 ──────────── 潮流 ▶
```

「溫暖、善於傾聽、有品味的摯友。專業但不高冷，細膩但不做作。
**讓人感覺被理解，而不是被推銷。**」

### 3.3 ✗ 避免這樣說（p.8）

```
「限時優惠，下單再打 9 折！」      → 對應 daily-sop.md 禁用詞：優惠、限時
「頂級 18K 金，奢華絕美工藝。」    → 對應 jessica-voice.md：不賣弄術語
```

### 3.4 品牌 DNA 自我檢查（p.7）

> 每推出新產品或內容前，問一句——這件事有沒有體現「**人、故事、獨一、永恆**」？
> 如果一個都沾不上，它可能不屬於 Tru-Mi。

## 4. Threads 內容軸（品牌手冊 p.15）

目標印象：「**很棒、特別有想法的設計師**」。手冊明載 **Threads 不需要美圖**。

| 軸 | 內容 |
|---|---|
| 設計師觀點 | 對設計、情感、人生時刻的真實想法。有觀點才被記住 |
| 幕後故事 | **（客戶同意下）** 訂製背後的故事與設計思考，最易引發共鳴 |
| 訂製眉角 | 「客製和現成差在哪」「離婚戒怎麼重生」——有用的內容被收藏 |
| 真誠互動 | 回覆留言、參與討論，**比單向發文更能養出黏著受眾** |

⚠️「幕後故事」那條的**（客戶同意下）**是品牌正本的限制條件，
與 `daily-sop.md`「未經另一當事人同意的私人故事，不擴大使用」一致。

✅「真誠互動」這條是 `daily-sop.md §4.8 Conversation Loop` 的品牌正本背書——
互動優先於發文不是我們推論出來的，是品牌策略本來就這樣定的。

## 5. 語氣是篩選工具，不是裝飾（p.13）

品牌手冊的「找到對頻客人：四道篩選機制」第二道：

> **用語氣篩選**：品牌語氣走「溫暖、有想法、有質感」。
> 重視這件事的人留下，不重視的人走開。

這解釋了為什麼語氣不能為了觸及而妥協——**語氣本身就是客群濾網**。
寫得像促銷會吸引到錯的人，那比沒有觸及更糟。

## 6. Evidence Gate：品牌主張 ≠ 已驗證的市場事實

品牌手冊中的市場判斷（例如某些場景「市場幾乎沒有對手深耕」、某客群「客單最高」）
是**品牌自身的策略主張**，**不是外部市場證據**。

```
可以說：品牌手冊把 X 定義為差異化方向
不得說：X 是已驗證的市場缺口／低競爭／高客單
```

要主張後者，需要另外的外部查證，且證據要另外存。

> 這一條是接 2026-09-11 的實際教訓：
> Jessica 的一句觀察「好像沒有人把它統整出來」曾被 AI 擴寫成
> 「高需求、低競爭、完全沒有品牌承接」。
> 詳見 `jessica-voice-samples.md` N-002。
> **品牌手冊是內部文件，它的市場判斷同樣適用這條 Gate。**
