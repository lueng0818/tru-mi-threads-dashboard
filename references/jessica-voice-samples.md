## 使用規則

```
一筆新語料 ≠ 自動成為 Voice Rule
```

樣本要升格成規則，必須通過 `jessica-voice.md` 的 **Rule Generalization Gate**。
本檔只負責如實保存，不做歸納、不下結論。

**分層強制**：每一筆都要分開記「原文」與「推論」。
原文是事實，推論是我們的解讀，兩者不得混寫成同一段。

## 樣本分級（2026-09-11 新增）

每一筆語料必須帶等級標記。位階規則在 `jessica-voice.md §0.3`，本節只記等級歸屬。

- emoji 1 個，在句尾
- 刪節號用 `⋯`
- 沒有 hashtag、沒有連結、沒有 CTA
- 第二則交代情境（誰、卡在哪、什麼感覺），不交代解法

## S-006｜修復型故事發文（自己發文）

**日期**　2026-07-16　**帳號**　@trumi_jessica
**情境**　收到一枚送修的舊鑽戒，把過程寫成一則貼文
**分級**　GROUND TRUTH（2026-09-11 自 Threads 帳號逐字收錄，公開貼文）

**原文**
```
今天收到一枚舊鑽戒
客人不確定當初買的是什麼材質
也不知道是不是真鑽
只知道六個爪子都斷了
想問問看還能不能修🤔

收到戒指後，我看了一下內圈：
「咦，原來是 PT900」
仔細檢查後，發現主石也是真鑽！！

聊著聊著才知道，
原來這是客人爸爸買送媽媽的
客人笑著說：
「這應該是我爸爸人生少數的浪漫。」

突然覺得， 修復的好像不只是一枚戒指，
而是一段值得被好好保存的浪漫回憶。
```

**可觀察事實（不是規則）**
- 開場是**動作**：「今天收到一枚舊鑽戒」——不是道理，也不是問句
- 敘事照時間順序走：收到 → 看內圈 → 檢查主石 → 聊天 → 才知道來歷。沒有先下結論再回頭解釋
- 用**引號**引自己心裡的話（「咦，原來是 PT900」）與客人的話（「這應該是我爸爸人生少數的浪漫。」）
- 驚嘆號連用 `！！` 掛在專業判斷上：「發現主石也是真鑽！！」
- emoji 1 個且在句尾（🤔）｜無破折號｜無 hashtag｜無連結｜無 CTA
- 專業資訊（PT900、六爪斷裂、主石真偽）**掛在情節上**，不是單獨陳列規格

**⚠️ 這一筆的邊界（收錄時即註明）**
結尾「修復的好像不只是一枚戒指，而是一段值得被好好保存的浪漫回憶」
帶「值得」與價值上升語氣，形狀接近 N-004（文青式金句收尾）。
**但它是 Jessica 本人寫的。** 依 §0.3，GROUND TRUTH 不因為像某個負向樣本而降級。
反過來也不成立：⛔ **不得**拿這一句去背書 AI 生成的金句收尾。
它只證明「她在自己的**故事型發文**裡會收在一句感想」，
不證明「海巡留言可以收金句」——情境不同，依 §0.1 不得跨情境推論。

## 消費者慣用語庫（2026-09-11 新增）

> **語料來源就是儀表板本身**：229 則貼文原文（`.post-content`）
> ＋數千則真實留言（`.comment-text`）。全部是台灣人在講婚戒。
>
> ⚠️ 這是**消費者**的語感，不是 Jessica 的。兩者都要參考，但
> Jessica 的語域以本檔上半部的 S-001～S-005 為準——她是設計師，不是路人。

### 用法：寫完一句問自己

```
這個說法，在語料庫裡找得到同類表達嗎？

有人這樣講           → ✅ 放行
沒有，但只是普通白話   → ✅ 放行（白話不需要出處）
沒有，而且是「寫出來的」→ ⛔ 砍掉，換白話
```

抓的是**表達方式**不是詞彙比對。不要因為某個詞沒出現就換掉，
要看**這種說話方式**真人會不會用。

### 實測案例：「儀式感」

`grep` 全語料，真人的講法：

```
儀式感有到位就好              只是想買個儀式感
但只需要個儀式感              有儀式感但又不會很難搭配
省時省力但又有儀式感           想要有點儀式感的時候
幸福比儀式感重要
```

**全部把「儀式感」當成一個可以買、可以有、可以到位的普通名詞。零比喻。**

AI 寫的「儀式感其實不用**靠石頭撐**」在語料庫裡找不到任何同類表達
→ 判定為發明的說法 → 改大白話「其實不用勉強」。（見 N-005）

### 觀察到的高頻表達（持續累積）

| 類型 | 真人怎麼講 |
|---|---|
| 程度副詞 | **蠻**可惜的／**蠻**中肯／**蠻**不錯／**超**難戴 |
| 嫌貴 | 鑽戒蠻**盤**的 |
| 務實 | 省時省力／打發自己／能天天戴／好搭配 |
| 求助起手式 | 有沒有人⋯／想問一下⋯／求推薦／萬事問脆友 |
| 描述困擾 | 卡卡的／硌手／勾到／戴不住／很難搭 |

⚠️ **不得為了「像真人」而硬塞這些詞。** 這是理解客群怎麼說話，
不是提供一個語助詞清單去套。硬套會變成另一種假（同 §4.8.6 的警告）。
