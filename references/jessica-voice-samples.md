# Jessica Voice Samples（真實語料庫）

> **這個檔案只放證據，不放規則。**
> 規則在 `jessica-voice.md`，什麼時候套用在 `daily-sop.md`。
>
> 建立於 2026-09-11。建立原因：先前的 Voice 規則是從抽象品牌語氣**推論**出來的，

```

**分層強制**：每一筆都要分開記「原文」與「推論」。
原文是事實，推論是我們的解讀，兩者不得混寫成同一段。

## S-001｜開話題（自己發文）

**日期**　2026-09-06
**情境**　朋友戒指卡住求救，Jessica 以此開一則 Threads 話題
**帳號**　@trumi_jessica　**串文結構**　1/2 + 2/2

**原文**
```
1/2  有人遇過戒指戴進去，拔不出來的狀況嗎？

2/2  朋友跟我求救，卡在關節的地方，越拔越痛⋯😭
```

**外部確認**　行銷顧問 Bevis：「可以唷！！！！！！！」「很讚～」

**可觀察事實（不是規則）**
- 開場是**問句**，不是知識點
- 沒有給答案，把答案留給留言區
- emoji 1 個，在句尾
- 刪節號用 `⋯`
- 沒有 hashtag、沒有連結、沒有 CTA
- 第二則交代情境（誰、卡在哪、什麼感覺），不交代解法

## S-002｜接球（回自己貼文下的留言者）

**日期**　2026-09-06 ～ 09-07
**情境**　網友在 S-001 底下提供方法

**原文**
```
網友 @yi_ting_wang83：肥皂或是乳液🥺
Jessica：            肥皂洗手是好方法欸！

網友 @jackochen1984： 用乳液
Jessica：            好方法呢！！

網友 @jackochen1984： 有成功嗎？
Bevis 指導：          不用，就是繼續跟他聊～ / 你試試看之類的
Jessica（提案）：      我們試試看⋯⋯⋯
Bevis 確認：          可以唷！/ 真的就把它當作朋友聊天就好
```

**可觀察事實**
- 長度 **6–10 字**
- 沒有 Tru-Mi、沒有婚戒、沒有設計師身分、沒有專業知識、沒有 CTA
- 不重述對方剛講的內容
- 驚嘆號連用（`！！`）
- 語尾詞：`欸`、`呢`
- 面對「有成功嗎？」**沒有交代結果**，把球留在場上

**⚠️ 這一筆的邊界（2026-09-11 補註）**
Bevis 那句「不用，就是繼續跟他聊」是**針對這一次閒聊追問**的指導。
當時對方不是真的需要一個答案。
**不得**據此推論成「Threads 一律不要直接回答」——那會傷到真正在求助的人。
（此邊界即為 `jessica-voice.md` Rule Generalization Gate 的觸發案例之一。）

## S-003｜海巡留言（陌生人的貼文）

**日期**　2026-09-07
**對象**　@lucia_____liu（婚戒是否一定要大品牌／終身保固重不重要）
**成效**　❤️6／0 回覆
**意義**　連續五週留言零產出後的唯一一次突破

**原文**
```
婚戒設計師路過
剛好最近自己也在籌備婚禮特別有感～
婚戒對自己的意義是什麼呢？
是承諾、習俗需要、還是不想有遺憾⋯

分享一對可愛婚戒

但希望在婚紗照留紀念😃
```

**Jessica 自己的疑問**　「我如果用以下的回法會不會太正式？」
**外部確認**　挖趣整合行銷：「可以喔！」

**可觀察事實**
- 長度 **約 90 字**，是 S-002 的十倍
- 開頭輕描淡寫自我定位：「婚戒設計師路過」，不是「我是 Tru-Mi 設計師」
- 揭露自己的處境（正在籌備婚禮）建立同理，不是建立權威
- 用**提問**帶出觀點，不直接下結論
- 附一個**真實案例**（新娘小名＋新郎羽球），且如實說「他們平時也不常戴」——不修飾成完美結局
- 未放連結、未自薦、未點名同業、未提價格

## S-004｜實用整理型發文

**日期**　2026-09-11
**情境**　看完 S-001 留言區的各種經驗後整理
**外部確認**　挖趣整合行銷：「可以喔！」

**原文**
```
看了 thread 友戒指卡住的經驗，真的很驚險⋯
前 3 名是
1.早上水腫
2.套錯手指
3.懷孕中後期手指變大

拔之前先塗護手霜，降低摩擦與拔的疼痛感，
硬拔手指頭會腫，反而會卡住😢

如果卡很久，手指都發紫了，
先冰敷然後到消防局、醫院剪開戒指
（真的不用怕破壞戒指，戒指都可以修）
```

**可觀察事實**
- 開場是**具體情境**（看了脆友的經驗），不是道理
- 編號列點——這裡的編號是內容本身（三種狀況），不是把散文切碎
- 專業判斷掛在使用情境上：「硬拔手指頭會腫，反而會卡住」
- 結尾是**判斷**不是金句：「戒指都可以修」
- 明確導向專業求助（消防局、醫院），不獨佔問題
- emoji 1 個在句尾｜無破折號｜無 hashtag｜無連結

## 消費者慣用語庫（2026-09-11 新增）

> **語料來源就是儀表板本身**：229 則貼文原文（`.post-content`）
> ＋數千則真實留言（`.comment-text`）。全部是台灣人在講婚戒。
>
> ⚠️ 這是**消費者**的語感，不是 Jessica 的。兩者都要參考，但
> Jessica 的語域以本檔上半部的 S-001～S-005 為準——她是設計師，不是路人。

### 用法：寫完一句問自己

```
這個說法，在語料庫裡找得到同類表達嗎？

有人這樣講           → ✅ 放行
沒有，但只是普通白話   → ✅ 放行（白話不需要出處）
沒有，而且是「寫出來的」→ ⛔ 砍掉，換白話
```

抓的是**表達方式**不是詞彙比對。不要因為某個詞沒出現就換掉，
要看**這種說話方式**真人會不會用。

### 實測案例：「儀式感」

`grep` 全語料，真人的講法：

```
儀式感有到位就好              只是想買個儀式感
但只需要個儀式感              有儀式感但又不會很難搭配
省時省力但又有儀式感           想要有點儀式感的時候
幸福比儀式感重要
```

**全部把「儀式感」當成一個可以買、可以有、可以到位的普通名詞。零比喻。**

AI 寫的「儀式感其實不用**靠石頭撐**」在語料庫裡找不到任何同類表達
→ 判定為發明的說法 → 改大白話「其實不用勉強」。（見 N-005）

### 觀察到的高頻表達（持續累積）

| 類型 | 真人怎麼講 |
|---|---|
| 程度副詞 | **蠻**可惜的／**蠻**中肯／**蠻**不錯／**超**難戴 |
| 嫌貴 | 鑽戒蠻**盤**的 |
| 務實 | 省時省力／打發自己／能天天戴／好搭配 |
| 求助起手式 | 有沒有人⋯／想問一下⋯／求推薦／萬事問脆友 |
| 描述困擾 | 卡卡的／硌手／勾到／戴不住／很難搭 |

⚠️ **不得為了「像真人」而硬塞這些詞。** 這是理解客群怎麼說話，
不是提供一個語助詞清單去套。硬套會變成另一種假（同 §4.8.6 的警告）。

### N-002｜把觀察升格成市場結論

```
Jessica 原句：「好像沒有人把它統整出來！」（滑貼文的印象）
AI 擴寫：    「高需求、低競爭、且完全沒有品牌在承接的長尾題」

### N-005｜發明比喻（且一度被寫進正面範例）

```
❌「儀式感其實不用靠石頭撐」
✅「其實不用勉強」
```
**問題**　石頭＝鑽石、撐＝支撐儀式感，是一個發明的比喻。讀起來漂亮，
**而那正是問題**——5 筆樣本比喻出現 0 次，她寫的是「硬拔手指頭會腫，
反而會卡住」這種直述因果。
**語料庫驗證**　全語料 grep「儀式感」，真人講的是「儀式感有到位就好」
「只是想買個儀式感」，零比喻。
**更嚴重的是**　這句一度被寫進 `jessica-voice.md` §7.0 的「✅ 正面範例」。
**把發明的說法放進正面範例，比留在草稿裡更糟**，因為它會被當成標準複製下去。
**判斷法**　一句話如果讓人覺得「寫得真好」，多半就該砍掉。
Jessica 不是在展示文筆，她是在跟人講話。
**日期**　2026-09-11，由使用者指出「也不是慣用語」。

### N-006｜只查用詞不查結構

**問題**　檢查一則 150 字的海巡留言，查出 6 處用詞問題（破折號、
「另外提醒一件事：」、「這個方向很實用」等），全部是**表面標記**。
使用者回覆：「這樣的寫法都還是很 AI 感，而且做為貼文開頭，很難理解。」
**真正的問題**　一整塊零斷行、假設句開頭沒有人稱、三個主題擠在一起、
沒有問句收尾。**改完那 6 處，它仍然是同一塊東西。**
**修正**　`jessica-voice.md` §7.0 新增「結構層先看，用詞層後看」。
**日期**　2026-09-11。

### N-003｜過度工整的公關式留言

```
❌ 分開準備最實際的差別，其實在戴的頻率上。每天戴的那一隻會被洗手、
   鍵盤、提袋反覆磨到，所以戒圈的厚度跟內側的弧度，比款式更決定你戴
   不戴得住。可以先看看自己一天裡手會做哪些事，再回頭決定那兩隻各自
   要負責什麼。
```
**問題**　三句都在給結論，沒有一句是「聽到對方說了什麼」。像顧問回答，不像朋友接話。
**額外問題**　使用破折號（真實樣本 0 次）。

### N-004｜文青式金句收尾

```
❌「因為它是照著你們兩個人長出來的。」
❌「這件事比戒指本身重要。」
```
**問題**　價值上升句型。砍掉第一句後又補了同族的第二句——換湯不換藥。
