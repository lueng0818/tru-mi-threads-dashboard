## S-001｜開話題（自己發文）

**日期**　2026-09-06
**情境**　朋友戒指卡住求救，Jessica 以此開一則 Threads 話題
**帳號**　@trumi_jessica　**串文結構**　1/2 + 2/2

**原文**
```
1/2  有人遇過戒指戴進去，拔不出來的狀況嗎？

2/2  朋友跟我求救，卡在關節的地方，越拔越痛⋯😭
```

**外部確認**　行銷顧問 Bevis：「可以唷！！！！！！！」「很讚～」

**可觀察事實（不是規則）**
- 開場是**問句**，不是知識點
- 沒有給答案，把答案留給留言區
- emoji 1 個，在句尾
- 刪節號用 `⋯`
- 沒有 hashtag、沒有連結、沒有 CTA
- 第二則交代情境（誰、卡在哪、什麼感覺），不交代解法

## S-002｜接球（回自己貼文下的留言者）

**日期**　2026-09-06 ～ 09-07
**情境**　網友在 S-001 底下提供方法

**原文**
```
網友 @yi_ting_wang83：肥皂或是乳液🥺
Jessica：            肥皂洗手是好方法欸！

網友 @jackochen1984： 用乳液
Jessica：            好方法呢！！

網友 @jackochen1984： 有成功嗎？
Bevis 指導：          不用，就是繼續跟他聊～ / 你試試看之類的
Jessica（提案）：      我們試試看⋯⋯⋯
Bevis 確認：          可以唷！/ 真的就把它當作朋友聊天就好
```

**可觀察事實**
- 長度 **6–10 字**
- 沒有 Tru-Mi、沒有婚戒、沒有設計師身分、沒有專業知識、沒有 CTA
- 不重述對方剛講的內容
- 驚嘆號連用（`！！`）
- 語尾詞：`欸`、`呢`
- 面對「有成功嗎？」**沒有交代結果**，把球留在場上

**⚠️ 這一筆的邊界（2026-09-11 補註）**
Bevis 那句「不用，就是繼續跟他聊」是**針對這一次閒聊追問**的指導。
當時對方不是真的需要一個答案。
**不得**據此推論成「Threads 一律不要直接回答」——那會傷到真正在求助的人。
（此邊界即為 `jessica-voice.md` Rule Generalization Gate 的觸發案例之一。）

## S-003｜海巡留言（陌生人的貼文）

**日期**　2026-09-07
**對象**　@lucia_____liu（婚戒是否一定要大品牌／終身保固重不重要）
**成效**　❤️6／0 回覆
**意義**　連續五週留言零產出後的唯一一次突破

**原文**
```
婚戒設計師路過
剛好最近自己也在籌備婚禮特別有感～
婚戒對自己的意義是什麼呢？
是承諾、習俗需要、還是不想有遺憾⋯

分享一對可愛婚戒
是用新娘小名跟新郎喜歡的羽球
做設計的，他們說平時也不常戴
但希望在婚紗照留紀念😃
```

**Jessica 自己的疑問**　「我如果用以下的回法會不會太正式？」
**外部確認**　挖趣整合行銷：「可以喔！」

**可觀察事實**
- 長度 **約 90 字**，是 S-002 的十倍
- 開頭輕描淡寫自我定位：「婚戒設計師路過」，不是「我是 Tru-Mi 設計師」
- 揭露自己的處境（正在籌備婚禮）建立同理，不是建立權威
- 用**提問**帶出觀點，不直接下結論
- 附一個**真實案例**（新娘小名＋新郎羽球），且如實說「他們平時也不常戴」——不修飾成完美結局
- 未放連結、未自薦、未點名同業、未提價格

## S-004｜實用整理型發文

**日期**　2026-09-11
**情境**　看完 S-001 留言區的各種經驗後整理
**外部確認**　挖趣整合行銷：「可以喔！」

**原文**
```
看了 thread 友戒指卡住的經驗，真的很驚險⋯
前 3 名是
1.早上水腫
2.套錯手指
3.懷孕中後期手指變大

拔之前先塗護手霜，降低摩擦與拔的疼痛感，
硬拔手指頭會腫，反而會卡住😢

如果卡很久，手指都發紫了，
先冰敷然後到消防局、醫院剪開戒指
（真的不用怕破壞戒指，戒指都可以修）
```

**可觀察事實**
- 開場是**具體情境**（看了脆友的經驗），不是道理
- 編號列點——這裡的編號是內容本身（三種狀況），不是把散文切碎
- 專業判斷掛在使用情境上：「硬拔手指頭會腫，反而會卡住」
- 結尾是**判斷**不是金句：「戒指都可以修」
- 明確導向專業求助（消防局、醫院），不獨佔問題
- emoji 1 個在句尾｜無破折號｜無 hashtag｜無連結

```
❌「你那句『超怕最後只能其中一人讓步』我看了有點停住。」
❌「你形容手指的那段我笑出來。」
```

### N-002｜把觀察升格成市場結論

```
Jessica 原句：「好像沒有人把它統整出來！」（滑貼文的印象）

```

### N-003｜過度工整的公關式留言

```
❌ 分開準備最實際的差別，其實在戴的頻率上。每天戴的那一隻會被洗手、
   鍵盤、提袋反覆磨到，所以戒圈的厚度跟內側的弧度，比款式更決定你戴
   不戴得住。可以先看看自己一天裡手會做哪些事，再回頭決定那兩隻各自
   要負責什麼。
```
**問題**　三句都在給結論，沒有一句是「聽到對方說了什麼」。像顧問回答，不像朋友接話。
**額外問題**　使用破折號（真實樣本 0 次）。

### N-004｜文青式金句收尾

```
❌「因為它是照著你們兩個人長出來的。」
❌「這件事比戒指本身重要。」
```
**問題**　價值上升句型。砍掉第一句後又補了同族的第二句——換湯不換藥。
